# play-zone

A just-for-fun browser game. Open `index.html` in a browser to play.

- `PLAN.md` — Plan und Bauschritte (Deutsch): Minecraft-Spiel mit Pferden in Zug
- `GAME_IDEA.md` — idea sheet to fill in before building
- `CLAUDE.md` — rules for building the game with Claude
- `GAME_DAY.md` — step-by-step guide for the day, plus a simple tech overview
